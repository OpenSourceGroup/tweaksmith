# Governance

Tweaksmith is an [Open Source Group](https://osg.co.in) project.

**Kamyab Infotech** ([kamyab.co.in](https://kamyab.co.in)) is the current lead maintainer.

## How the project runs

- Contributions go through GitHub pull requests and issues: [OpenSourceGroup/tweaksmith](https://github.com/OpenSourceGroup/tweaksmith).
- Releases are published by authorized maintainers. Draft and unsigned builds are not Gatekeeper-ready.
- Report security issues as described in [SECURITY.md](SECURITY.md) (security@kamyab.co.in).
- Source code is [MIT](LICENSE).
